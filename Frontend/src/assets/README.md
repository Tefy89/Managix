# Recursos visuales locales

Los dashboards de ESTUDIANTE, DOCENTE y ADMINISTRADOR se construyen con componentes Angular y estilos CSS; sus mockups son referencias de diseño y no son recursos de la aplicación.

Los recursos que se muestran en la interfaz se almacenan localmente en:

- `images/institution/` para el logo institucional.
- `images/login/` para la imagen visual del inicio de sesión.
- `images/portal/` para recursos editoriales del Portal Académico.
- `icons/` para iconografía local propia.

No se usan URLs externas para recursos visuales esenciales.
